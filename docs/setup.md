# Setup

## Windows

1. Install Go from the official Go website.
2. Verify the installation with `go version`.
3. Clone this repository and run `go mod tidy`.
4. Run `go run verify.go` to confirm the scaffold is present.

## Linux

1. Install Go using your package manager or the official tarball.
2. Verify the installation with `go version`.
3. Clone this repository and run `go mod tidy`.
4. Run `go run verify.go` to confirm the scaffold is present.

## macOS

1. Install Go from the official Go website or Homebrew.
2. Verify the installation with `go version`.
3. Clone this repository and run `go mod tidy`.
4. Run `go run verify.go` to confirm the scaffold is present.
