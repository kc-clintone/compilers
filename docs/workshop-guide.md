# Workshop guide

## Schedule

The workshop is structured as a series of small milestones.

1. Introduce the compiler pipeline and repository layout.
2. Implement tokens and the lexer.
3. Build parsing logic for expressions and statements.
4. Create the AST and connect it to the parser.
5. Add an interpreter to evaluate simple programs.
6. Add a compiler that emits pseudo-assembly.
7. Optional bonus work and extensions.

## Exercise flow

Each exercise focuses on one part of the pipeline. Participants should implement the required functionality in the corresponding package and then test the result with small example programs.

## Expectations

- Keep changes small and focused.
- Prefer clear, simple code over clever solutions.
- Document design decisions as you go.
- Reuse the placeholder structure rather than introducing a large alternative architecture.
