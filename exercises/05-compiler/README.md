# Exercise 5: Compiler

## Objective

Implement a compiler that emits simple pseudo-assembly instructions.

## Expected outcome

Your compiler should produce a sequence of instructions for a simple program.

## Hints

- Keep the instruction set small and human-readable.
- Translate one expression form at a time.
- Treat the compiler as a structured code generator rather than an interpreter.
