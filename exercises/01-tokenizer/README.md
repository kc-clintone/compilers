# Exercise 1: Tokenizer

## Objective

Implement a lexer that scans source text into tokens.

## Expected outcome

You should be able to tokenize simple input such as integers, identifiers, operators, and punctuation.

## Hints

- Start by defining token types.
- Build the lexer around a small state machine.
- Focus on one or two operators first, then expand.

## Files to modify

- internal/token/token.go
- internal/lexer/lexer.go
